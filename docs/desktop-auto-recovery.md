# 桌面 CDP 自动恢复

启动器在有插件使用桌面，或有插件等待桌面连接时监测连接。默认开启自动恢复和自动重启，默认不跳过任务保护。可在“桌面”页保存这三项策略；配置在 `~/.codex-launcher/config.json` 的 `desktop` 对象中。

| 字段 | 默认行为 |
| --- | --- |
| `autoReconnect` | 未设置或 true：持续重连；false：停止自动恢复 |
| `autoRestart` | 未设置或 true：持续故障时考虑重启；false：只重连 |
| `restartDuringTasks` | 未设置或 false：保护最近探测到的任务；true：允许故障重启中断任务 |

监测间隔5秒；重连按2、5、10、20、30秒的最小间隔退避。连续故障至少60秒且至少尝试过3次恢复，才考虑自动重启；重启之间至少间隔10分钟，每小时最多3次。电脑休眠后会重新给予恢复宽限期。

任务保护使用只读的已加载会话与状态查询，覆盖可查询的已连接主机。最近成功探测显示忙碌或未知时暂缓重启；仅最近两分钟内的空闲快照可允许重启。快照不代表断线期间能实时观察所有新任务，超过有效期后也只继续重连。允许中断任务的选项会跳过这项保护。

短暂断线优先重建连接和使用它的插件，Web重新连接后读取历史。只恢复原来运行或等待中的桌面插件；手动停止、禁用或卸载的插件不会被重新启动。其他插件不因桌面连接恢复而重启。

同文档导航保留有效监听；真正页面重载、窗口关闭或超时会触发恢复。CDP评估、注入刷新和清理均有超时。停止及退出会取消排队恢复，并在实际终止或启动桌面进程前再次检查取消状态。

自动恢复不会重发消息、文件写入、引导或审批。遇到 `ACTION_WRITE_UNKNOWN` 仍需根据会话历史确认实际结果。恢复动作和失败原因可在启动器“日志”页查看。
