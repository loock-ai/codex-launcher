# 统一启动器插件实施计划

设计依据：../specs/2026-10-12-launcher-plugin-runtime-design.md。用户已指示实施。

- [x] 通用插件运行器：v2 main/ui/desktop，独立后台进程，配置隔离、启停、自启、IPC与故障回收，兼容v1脚本。
- [x] DesktopService：独立配置和引用租约，控制代理、Dots请求与注入服务；Mobile关闭不影响其他插件。
- [x] Mobile插件：自行拥有配置、三种网关模式、后台启动停止、Web资源与启动器管理页面。
- [x] 启动器外壳：通用插件列表、状态、UI容器、frame身份校验、共享桌面设置与核心操作。
- [x] 配置迁移与打包：备份旧配置并迁移Mobile字段，保留端口、口令和已保存插件状态；插件产物可独立从配置目录加载。
- [x] 单元、迁移、独立进程与受控浏览器验收；不以工具运行真实桌面注入。

实现约定：第一阶段可信本地插件；Node子进程隔离故障，不宣称恶意第三方沙箱。Mobile后台以CJS bundle交付并使用宿主依赖路径；UI以独立静态页面交付。插件宿主不导入Mobile业务模块。

## 实施验收

- 完整回归：632 项通过，11 项受环境门控测试默认跳过。
- 启动器与服务端 TypeScript、Web/Mobile/启动器构建通过。
- 独立 worker 集成验证实际 HTTP 服务、断线重连、停止 Mobile 后时间插件保留。
- 2 项受控 Electron 测试验证真实插件页面加载、桥接、二维码、配置保存回读、启停和表单隔离；不连接真实 ChatGPT 账户。
- macOS arm64 应用打包成功；以 Node 模式执行包内 worker，验证 ASAR 模板复制、独立插件启动与 HTTP 200。
- 原配置及正在运行的正式启动器未替换；当前功能保留在工作树，未推送。
