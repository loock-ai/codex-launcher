# 重启GPT期间保持Web在线实施计划

目标：重启ChatGPT只暂停桌面通道，Mobile网页及WebSocket持续在线，桌面就绪后恢复连接。

方案：为插件增加可选的桌面暂停/恢复生命周期；Mobile保留网关，通过可重新绑定的代理释放、重建桌面租约；不支持此生命周期的插件继续停止后启动。managed/external模式无需暂停上游。桌面暂未就绪时重试恢复，不重建网关。旧版插件兼容原流程。

- [x] 编写失败测试：重启阶段HTTP可访问、同一WebSocket仍可请求状态，恢复后RPC成功，连续两次有效。
- [x] 宿主worker/PluginManager支持可选暂停与恢复，Controller重启流程使用它，恢复失败进入原自动重试机制。
- [x] Mobile代理可解绑和重新绑定租约，Dots使用当前租约；发送桌面暂停/恢复事件，前端不关闭WebSocket。
- [x] 运行宿主与插件测试、类型检查和构建；验证本机与Macmini服务、保持配置和token。

验证使用注入的桌面重启替身，不终止本次正在运行的ChatGPT。

验证结果：宿主相关61项、后续新增延迟恢复用例通过；插件16项、两仓库类型检查和构建通过。额外跨进程集成验证CDP/native各连续两轮重启，同一WebSocket及HTTP在重启回调内持续可用，恢复RPC正常。本机和Macmini已安装，插件均运行、项目API返回200，配置文件逐字节保持一致。未真实终止ChatGPT。
