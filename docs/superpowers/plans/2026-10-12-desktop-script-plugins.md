# 桌面脚本插件实现计划

已确认需求：插件代码独立放在启动器配置目录；启动器读取并管理是否注入。首个插件为桌面会话列表显示最近更新时间，参考 Web，相对时间和悬停完整时间。无需修改桌面安装包。

- 插件目录：配置目录/plugins/<plugin-id>/，含 manifest.json 与 inject.js；启动器内只保留通用加载和生命周期管理。
- 首次使用将仓库 plugins/ 模板复制到配置目录，已有文件不覆盖；启用状态单独保存于 plugins.json。
- 首个插件默认关闭，由用户在启动器插件页开启。停止桥接、关闭开关时释放观察器和时间标签；页面重载后重新注入。
- 脚本必须提供 dispose；启用失败应清理，错误独立展示；不允许任意外部路径作为 entry。
- 更新已复制脚本后通过重新加载生效，不重新构建启动器。暂不实现在线安装、下载或第三方沙箱。
- 测试：插件目录/状态/加载生命周期；原生标记模拟 DOM 的时间渲染、虚拟行复用和清理；受控 Electron/browser验证开关和页面重载。
- 实际受保护的 ChatGPT 不通过工具注入；安装后由用户操作插件开关。

验证记录：全量 584 项测试通过；受控桌面脚本和启动器页面浏览器集成通过，覆盖配置目录读取、开关、脚本修改重载、页面刷新重注入。实际 ChatGPT 由用户通过插件开关启用，未通过工具注入。

打包验收：修复Electron ASAR模板复制后，3项受控集成通过；安装后实际配置目录manifest与inject.js和源码SHA一致，初始关闭。
